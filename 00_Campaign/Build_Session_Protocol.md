BUILD SESSION PROTOCOL
Design the floor's physical space, mechanics, encounters, NPCs, and chaos engine tables.

# Load Phase
1. Master File Index — scan for current campaign state.
2. Combat Cheat Sheet — know what mechanics exist before designing new ones.
3. Character Index — know who exists.
4. Prior floor packages (if any) — for continuity and difficulty progression reference.
# Work Phase
1. Doug provides creative direction: floor theme, environmental concept, desired tone, specific mechanics or NPCs.
2. Narrator drafts Floor Design Doc (player-visible + narrator-only sections).
3. Narrator builds Chaos Engine tables (event tables, chaos clock pool, loot tables, encounter modifiers). Export to floor_NN_tables.json using TABLE_FORMAT.md as guide.
4. Narrator creates character files for any new NPCs. Add entries to Character Index.
5. Doug reviews player-visible portions. Adjustments as needed.
6. Update Combat Cheat Sheet if any new floor-specific mechanics. Increment version, update changelog.
7. Floor package sealed. Files saved to 02_Floors/Floor_XX/.
8. Update Master File Index and 02_Floors/_Index.docx with new floor entry.
