DISCOVERY INDEX
What the characters know. Lore, codes, techniques, intelligence.
Knowledge the characters have acquired that is not an item but affects what they can do. Passwords, override codes, lore about the dungeon's history, techniques learned from NPCs, intelligence about upcoming floors, maps of explored areas, documented procedures.
If a character learned it and might need it later, it goes here. The narrator checks this before any session involving exploration, puzzle-solving, or NPC interaction to know what the party already knows.

# Entry Format
Discovery: [What was learned]
Type: [CODE / LORE / TECHNIQUE / INTELLIGENCE / MAP / PROCEDURE / OTHER]
Source: [Who or what provided the information]
Session: [When it was learned]
Known by: [Which characters know this -- may not be the whole party]
Verified: [YES / NO / UNCERTAIN -- has it been tested or confirmed?]
Relevance: [Where/when this knowledge matters]
